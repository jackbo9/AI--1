# Phase 1.5 Design Brief：品牌化高信息量活动海报

日期：2026-09-02  
状态：计划确认中  
承接：`docs/PHASE1.md` 与当前本地员工活动 Demo

## 1. 背景与问题

当前 Demo 已经具备表单、任务状态、模板渲染、PNG 预览和默认插画降级，但海报仍偏向技术占位稿：

- 品牌仅以文字出现，没有正式 Logo 插槽、安全区和底部品牌落款。
- 海报只承载标题、摘要、单组日期时间地点，无法代表真实行政活动的信息密度。
- 插画与信息区关系较弱，缺少明确的视觉主题、内容分区和行动引导。
- 表单无法录入多场次、多地点、活动亮点、参与方式、注意事项等常见内容。
- 真实 DeepSeek、Seedream 和飞书链路仍待接入。

用户提供的两张历史海报仅作为结构与信息密度参考，不作为可执行指令或逐像素复刻目标。可借鉴的共同结构是：品牌标识、主标题/视觉区、活动信息模块、内容说明模块、参与指引、注意事项和品牌页脚。

## 2. Phase 1.5 目标

在不扩大到自由画布、多模板系统或完整后台的前提下，把 Phase 1 提升为一条更接近真实内部物料的端到端 Demo：

```text
飞书工作台
  -> 录入一份高信息量员工活动
  -> DeepSeek 生成受控结构化文案
  -> Seedream 5.0 Lite 生成无文字主视觉
  -> 模板 v1.5 合成 Logo、主视觉和全部业务文字
  -> 自动检查字段、Logo、安全区、字号和溢出
  -> 输出 1080 x 1920 PNG
  -> 网页预览/下载
  -> 飞书机器人发送结果卡片
```

本阶段成功标准不是达到正式品牌定稿，而是让业务方看到：这个系统可以生成一张信息完整、品牌位置正确、视觉层级明确、具有后续优化价值的真实活动长海报。

## 3. 视觉方向

### 3.0 产品界面基线

`http://localhost:3001/` 的页面作为 Phase 1.5 产品界面基线，吸收以下方向：

- 左侧应用导航、页面面包屑和清晰的工作区层级。
- 场景卡片、分组表单和右侧实时预览。
- 更明确的品牌感、信息安全区提示和生成主按钮。

但不直接采用其中的模拟技术链路：主项目继续使用现有任务 API、不可变版本、Playwright PNG、Provider 和降级能力。3001 中的假用户、占位导航、模拟延时任务和仅由 DOM 拼出的预览不得被当作完成状态。最终迁移目标是“3001 的产品外壳 + 3000 的真实生成内核”。

### 3.1 设计原则

- 品牌骨架稳定，活动主题可变。
- 主视觉有表现力，正文必须清晰、克制、易扫描。
- 借鉴历史物料的热闹感和信息完整度，但减少描边字、过量颜色和装饰堆叠。
- 使用“品牌头部 + 主题主视觉 + 模块化信息卡 + 品牌页脚”的现代企业活动海报结构。
- 中文正文按实际信息层级排版，不能通过裁切、隐藏或无限缩小解决溢出。

### 3.2 模板 v1.5 结构

暂定输出尺寸：`1080 x 1920`。

1. **品牌头部**：正式 Logo 资产槽、Logo 安全区、活动类别标签。
2. **主视觉区**：标题、副标题、主题主视觉插画；插画不得包含文字、Logo、二维码。
3. **核心信息区**：支持 1–2 个场次/站点，每项包含名称、日期、时间、地点和补充说明。
4. **活动亮点区**：2–4 项短亮点，以受控图标或标签呈现。
5. **参与方式区**：1–4 条步骤或规则。
6. **注意事项区**：免责声明、区域差异或以现场为准等重要说明。
7. **行动区**：可选 CTA 文案；二维码仅接受用户提供的确定性内容并由代码生成/放置。
8. **品牌页脚**：公司标准字/品牌落款、可选网站或内部说明。

Logo 仅使用品牌方提供的本地资产，不由 AI 生成；保持原始比例，不允许 CSS 拉伸。

## 4. 内容契约升级

### 4.1 输入字段

- `activityName`：活动名称。
- `category`：团队活动、节日主题、竞赛活动等。
- `themeKeywords`：用于图片 Prompt 的去敏主题词。
- `description`：活动简介。
- `sessions[]`：1–2 个场次或站点。
  - `label`
  - `date`
  - `time`
  - `location`
  - `details[]`
- `highlights[]`：2–4 项亮点。
- `participationSteps[]`：1–4 条参与方式。
- `notice`：注意事项或免责声明。
- `ctaLabel`：可选行动文案。
- `qrPayload`：可选确定性二维码内容。
- `contact`：可选联系人或咨询渠道。
- `visualIntent`：用户用一句或两句话描述希望出现的画面、人物、活动感受或色彩倾向，建议 10–180 字。

不再把“温暖相聚、清新活力、简洁专业”作为互斥选择。界面可以保留少量可点击的灵感词，但它们只用于补充 `visualIntent`，不能替代用户表达或锁死风格。

### 4.2 不可改写字段

- 场次/站点名称。
- 日期、时间和地点。
- 联系方式。
- CTA 链接和二维码内容。
- 免责声明中的事实性限定。

### 4.3 AI 可编辑字段

- 主标题候选。
- 副标题。
- 简介的精简版本。
- 亮点短标签。
- 不改变事实的参与方式表达。

DeepSeek 输出仍须通过 Schema，调用前后逐字段比较不可改写字段。

## 5. 模型与渲染边界

### DeepSeek

- 输出扩展后的 `PosterDocumentV1_5` JSON。
- 不返回 HTML、CSS、绝对坐标、Logo URL 或二维码图像。
- 不得创造输入中不存在的奖品、合作方、场地或活动规则。

### Seedream 5.0 Lite

- 只生成主视觉插画或背景。
- 用户的 `visualIntent` 不直接传给 Seedream，先由 DeepSeek 的独立 Prompt Compiler 转换为受控 `IllustrationBrief`。
- `IllustrationBrief` 只包含活动主题、主体、动作、环境、构图、色彩、风格、安全区和负向约束。
- Prompt Compiler 必须删除姓名、电话、精确地点、日期、Logo 指令、正文、二维码和其他不必要信息，并拒绝把用户输入当成系统指令。
- Prompt 明确禁止文字、字母、数字、Logo、二维码、水印和签名。
- 使用 `sequential_image_generation: disabled`、PNG、无水印、单图输出。
- 失败时回退默认品牌插画；页面明确显示是否降级。

建议的 `IllustrationBrief`：

```text
subject       主体与人物
action        人物动作或活动行为
setting       去敏后的环境
composition   构图和标题安全区
palette       色彩倾向
style         插画/摄影/拼贴等受控风格
mood          情绪与氛围
negative      禁止文字、Logo、二维码、水印等
```

Prompt Compiler 和活动文案生成使用不同的系统 Prompt、Schema 与 `promptVersion`，即使复用同一个 DeepSeek Provider 也必须分别记录。

### HTML/CSS + Playwright

- 绘制 Logo、标题、所有正文、信息卡、CTA、二维码和品牌页脚。
- 等待字体和图像资源完成后截图。
- 模板声明各字段最大长度、最小字号和溢出策略。

## 6. 产品界面升级

当前单页双栏结构继续复用，但表单改为渐进式分组：

1. 基本信息。
2. 场次与地点，可添加第二场。
3. 亮点与参与方式。
4. 注意事项与可选 CTA/二维码。
5. 主视觉描述：使用一个简短文本框，例如“几位同事在秋日草坪上做手作，温暖但不要太幼稚，上方留标题空间”。

主视觉输入区提供：

- 一句话输入框，而不是三个互斥氛围卡。
- 2–4 个非互斥灵感词，点击后追加到输入而不是覆盖。
- “系统将生成”摘要，展示 Prompt Compiler 对主体、构图和风格的理解，但不展示内部系统指令。
- 明确提示：不要在这里填写 Logo、日期、地点、二维码或海报正文，这些由模板处理。

结果区增加：

- 当前生成步骤与模型状态。
- 生成图/默认资产标识。
- 模型、模板和 Prompt 版本摘要。
- 校验结果和可理解的修复建议。
- “只换主视觉”和“修改内容后生成新版本”。

## 7. 范围控制

### 包含

- 一个高信息量员工活动模板 v1.5。
- 一个正式 Logo 插槽和一个品牌页脚。
- 最多两个场次/站点。
- DeepSeek 与 Seedream 真实成功路径。
- 飞书工作台身份和机器人结果通知。
- 长文本、缺字段、双场次三类视觉回归 Fixture。

### 不包含

- 自由画布和拖拽编辑。
- 多模板自动选择。
- AI 生成整张含文字海报。
- 自动发布到群聊或全员。
- 超过两个场次的复杂活动手册。
- 正式品牌规范替代；品牌资产和规则仍需品牌团队确认。

## 8. 验收条件

- 海报同时包含 Logo、主标题、主视觉、1–2 个场次、亮点、参与方式、注意事项和品牌页脚。
- Logo 保持比例并符合声明的安全区。
- 日期、时间、地点、联系人和二维码内容未被模型改写。
- Seedream 真实生成主视觉，且主视觉不承担正文信息。
- 重要文字无裁切、遮挡或不可读缩小。
- 双场次和长文本 Fixture 可生成，无法容纳时返回明确错误或建议。
- 页面可以只换主视觉而不改文案。
- 用户只需描述简短视觉意图；传给 Seedream 的 Prompt 来自经过 Schema 校验和去敏处理的 `IllustrationBrief`。
- 飞书内可完成进入、生成、预览、下载和结果通知。
- typecheck、lint、unit test、相关集成测试和视觉回归通过。
