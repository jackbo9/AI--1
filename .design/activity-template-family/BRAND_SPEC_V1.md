# BrandSpec v1｜员工活动模板家族

状态：已锁定  
锁定日期：2026-09-03  
适用范围：M1 员工活动/赛事类模板家族

## 1. 品牌头部

- 公司 Logo 位于左侧。
- 行政标识位于右侧。
- Logo 必须使用正式资产并保持原比例，位置、尺寸和安全区由各 RenderTarget 的模板元数据声明。

## 2. 品牌色

- `Admin Yellow = #FAE24C`。
- 该值是 BrandSpec v1 的唯一行政黄色 Token；不得使用模板 SVG 中的其他近似黄色替代。

## 3. 安全边距

- 不设跨规格统一像素值。
- 每个 RenderTarget 根据已确认模板独立声明 `safeArea`，至少覆盖 Logo、标题、正文、主视觉焦点、CTA/二维码及画布边缘。
- 安全边距属于确定性模板规则，不交由 LLM 或图片模型决定。

## 4. 标题层级

- `H0 = 120px`。
- `H1 = 80px`。
- 标题最多三行。
- 模板为标题槽位声明使用 H0 或 H1；超过三行属于阻断导出的错误，不允许裁切、隐藏或无限缩小。

## 5. 长图高度

- 长图宽度固定为 `1080px`，高度根据实际文案和启用模块自动计算。
- `1080x3000` 仅为设计样例，不是固定输出尺寸。
- 长图不得通过裁切正文满足固定高度。

## 6. 默认输出物料包

每次生成默认生产以下四种规格：

| RenderTarget | 尺寸 |
|---|---|
| `portrait_1080x1920` | `1080 x 1920` |
| `landscape_1920x1080` | `1920 x 1080` |
| `banner_2227x950` | `2227 x 950` |
| `longform_1080xAuto` | `1080 x Auto` |

- 用户不需要在生成前选择规格。
- 四种规格共享同一事实快照、已确认文案与视觉母题。
- 生成完成后，用户可以选择下载任一单项；P0 同时提供整组下载能力。
- 某一规格失败不得使其他已通过校验的规格失效。

## 7. 不变的系统边界

- LLM 只输出结构化文案或结构化视觉 Brief，不返回 HTML/CSS 或绝对坐标。
- 图片模型只生成无文字视觉素材，不生成 Logo、二维码、日期、地点或正文。
- HTML/CSS、Logo、标题、正文、二维码和最终尺寸由代码确定性控制。
- 每个 Artifact 必须记录 BrandSpec、模板、Prompt、模型、素材和内容版本。

## 8. P0 外部输入门槛

- 行政标识正式源文件及允许使用的颜色/反白版本。
- MiSans 可用于服务端渲染的字体文件和授权确认。

缺少上述资产时可以完成契约、编排和占位 Fixture，但不能建立正式视觉回归基线，也不能通过发布级品牌检查。
