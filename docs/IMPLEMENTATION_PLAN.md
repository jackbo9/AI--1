# Vibecoding 实施计划

原则：按可以独立演示和验证的纵向闭环推进，不先批量搭页面、数据库表或 Provider 空壳。

## Milestone 0：项目骨架与质量门槛

- [ ] 初始化 Next.js + TypeScript 项目。
- [ ] 配置 ESLint、格式化、Vitest 和 Playwright。
- [ ] 建立 `src/contracts`、`src/templates`、`src/worker` 等约定目录。
- [ ] 增加 `.env` 校验，缺少关键变量时启动即失败。
- [ ] 建立 Fixture 和视觉回归输出目录。
- [ ] CI 至少执行 typecheck、lint、unit test。

验收：无业务代码时，测试和构建命令可重复运行。

## Milestone 1：确定性渲染纵向闭环

- [ ] 定义第一个场景的 Zod Schema。
- [ ] 准备 3 组固定输入：正常、长文本、缺字段。
- [ ] 实现一个 HTML/CSS 模板。
- [ ] 嵌入并等待品牌字体加载。
- [ ] 使用 Playwright 输出固定尺寸 PNG。
- [ ] 实现字段完整性、Logo 和文本溢出检查。
- [ ] 生成视觉回归基线图。

验收：同一 Fixture 可重复输出相同结构的海报；缺字段和溢出有明确错误，重要文本不会静默丢失。

## Milestone 2：任务与版本闭环

- [ ] 实现 GenerationJob 和 GenerationVersion。
- [ ] 实现创建、查询和重试 API。
- [ ] Web 请求只创建任务，Worker 异步处理。
- [ ] 实现幂等键、步骤状态和错误码。
- [ ] 将 PNG 保存到 StorageProvider。
- [ ] 增加任务详情和预览页面。

验收：刷新网页不会丢失任务；重复提交不会重复计费；失败任务可重试。

## Milestone 3：LLM 文案与模板选择

- [ ] 实现 CopyProvider 接口和一个批准模型适配器。
- [ ] Prompt 输出受 JSON Schema 约束。
- [ ] 对不可改写字段做生成前后比较。
- [ ] 记录模型、Prompt 版本、耗时和用量。
- [ ] 支持用户编辑允许字段并生成新版本。

验收：时间、地点等不可改写字段保持原值；不合法输出不会进入渲染器。

## Milestone 4：受控插画生成

- [ ] 实现 IllustrationProvider。
- [ ] 将风格包、负向约束和安全区纳入请求。
- [ ] 插画不含文字、Logo 和二维码。
- [ ] 支持“只换插画”。
- [ ] 实现超时和默认品牌资产降级。

验收：图片模型失败仍能产出合规基础海报；只换插画不会改写文案。

## Milestone 5：飞书企业自建应用

- [ ] 创建测试企业自建应用。
- [ ] 配置网页应用和测试用户范围。
- [ ] 接入飞书身份并映射内部用户。
- [ ] 接入机器人任务通知和结果卡片。
- [ ] 验证事件/回调签名和重放防护。
- [ ] 可选：把任务摘要和反馈同步多维表格。

验收：测试用户可从飞书工作台免重复登录进入；生成结束收到结果卡片；飞书通知失败不影响任务结果。

## Milestone 6：三场景 MVP

- [ ] 业务方确认三个场景协议。
- [ ] 品牌设计确认模板和风格包。
- [ ] 增加多语言和多尺寸测试 Fixture。
- [ ] 实现模板选择、局部修改和导出。
- [ ] 埋点生成时间、一次通过率和修改次数。
- [ ] 组织 5–10 名行政专员可用性测试。

验收：三个场景均可完成输入—预览—修改—导出闭环，并得到业务、品牌和用户三方评价。

## 进入生产试点前单独立项

- [ ] 安全评审、数据分级和外部模型边界。
- [ ] PostgreSQL、对象存储、备份和灾难恢复。
- [ ] Redis/BullMQ 或企业统一任务平台。
- [ ] 限流、配额、成本预算和容量测试。
- [ ] 监控、告警、审计和运维责任人。
- [ ] 字体、插画、模型输出和品牌资产版权确认。
- [ ] 发布、回滚和模板版本治理。
