# 第一版锁定：同一母图裁切排版

分支：codex/feishu-workbench-iteration-20260913。PR 目标：codex/update-image-generation-logic。当前仍为本地身份试用版，不代表飞书生产部署验收。

## 最终范围

- 保留本轮空白表单、标题文案建议、可选二维码、可编辑名单及即时预览、按需 AI 描述、双方案及单项重试、统一大字 UI、连续缩放、PNG/JPG 下载。
- 两个竖版方向仍真实生图。确认一张之后，所有尺寸冻结该原图路径，使用模板等比例 cover 裁切，不再调用文生图、主体检测、蒙版或扩图服务。
- 竖版新母图保留完整画布构图；横版与 Banner 使用右侧居中裁切，长图使用顶部裁切以保护标题留白。裁切允许器材边缘缺失，不保证此前逐尺寸 XY 主体保护约束。
- 长图沿用名单布局自适应高度；本次无名单样张为 1080×2337。其余尺寸为 1080×1920、1920×1080、2227×950。海报字号不随操作界面字号变化。

## 接口与兼容

- Artifact 增加 adaptationMode=template-crop-v1、sourceVisualOptionId；assetPath 指向原始母图，既有 documentVersionId、visualFamilyId、templateVersion 继续绑定文案、视觉与模板版本。
- 竖版模板 2.5.0-mother-crop，额外规格 t01-2026-09-13-v10-mother-crop，避免命中先前独立生图产物。
- 原始母图在 claimFormat 时冻结，排版失败创建重试产物；不会重新调用图片模型。所选规格仍自动排版、逐项轮询展示。
- GET/POST master-protection 在身份和归属检查后返回 410 / MASTER_ADAPTATION_DISABLED。旧任务原图、版本、成品及额外历史字段保留，新流程不读取保护范围或派生信息。
- 本地 .next 曾包含未保存在当前源码中的扩图实现；本次从当前完整源码重新生产构建，移除了运行缓存与源码不一致的交付状态。未删除任务或生成文件。

## 验证记录

- TypeScript、ESLint、生产构建通过。
- 最终完整测试为 36 个文件、141 项单元/接口/正式渲染测试通过；包含废弃接口鉴权与 410 行为，以及裁切服务去重及失败重试不调用图片模型。
- 11 项浏览器回归通过：空白新建、名单连续输入与缺项提示、二维码链接及上传撤销、描述编辑与变量变化、失败及重复操作、任务恢复、1280/1440/1920/2560 宽度、自动多规格预览、连续缩放及三项模板对比度测试。
- 真实篮球任务 86fee8c4-af81-4a9e-a1c9-191b11a60868：AI 描述、人工编辑、两张 gpt-image-2 方案；一张首轮失败，单项重试成功，保留另一张。选图后四种成品与八个 PNG/JPG 下载成功；全部成品母图路径一致。
- 实际验收脚本 scripts/verify-crop-release.ts 需要 ALLOW_PAID_MODEL_PROBE=1；不传任务 ID 时创建真实描述和双图，传已存在验收任务 ID 时复用双图并重新排版。
- 样张及报告仅位于被忽略的 test-results/crop-release，不提交真实业务数据和模型凭据。
