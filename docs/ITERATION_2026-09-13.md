## 复验方式

使用独立测试副本，确保没有模型或飞书凭据。先启动本地服务：

```bash
AUTH_MODE=local READABILITY_MODE=trial LLM_PROVIDER= IMAGE_PROVIDER= npm run dev -- --hostname 127.0.0.1 --port 3213
```

另一个终端执行：

```bash
npm run typecheck
npm run lint
npm test
npx playwright test tests/e2e/iteration-one.spec.ts --workers=1
```

浏览器测试会创建本地测试任务与文件。生产构建请先停止开发服务，避免两个进程同时写入 .next；执行 npm run build 后可用同样的本地环境变量运行 npm start -- --hostname 127.0.0.1 --port 3213。
