## 3. 相对最初盘点已经解决的差异

- 长图参与对象、报名截止已接入；截止在多个位置引用同一个字段。
- 长图实际使用独立图槽与纯色内容区，不沿用竖版整图叠字布局。
- 二维码跟随报名区文档流，不再使用固定 `y=2563`；页脚保持底部留白，整张图在 1920–12000 内自适应。
- 横版与 Banner 保留所有场次，超出槽位时明确阻止，不默认只取首场。
- 无二维码时可显示已有联系人；未接入企业微信，也未增加二维码文件上传。
- 奖品没有获得独立展示槽位，因此仍保存并提示用途限制。

设计样例中的“请填写姓名／部门／联系方式”属于报名页面的操作说明，**不是制图用户新增的个人信息必填项**。

## 4. 当前运行方式与限制

1. 先完成允许导出的竖版，才能按需追加其他规格；当前不是一次点击自动生成整个物料包，也不能从长图直接开始。
2. 同一来源内容版本、视觉族和模板版本复用未失败 Artifact；失败重试生成新项。各规格状态、检查、错误及下载资格独立；不会因长图失败撤回竖版。
3. 新增规格仅复用已有资产并裁切／排版，不再次调用任何模型。竖版图未针对横幅重新构图，主体裁切效果仍需使用者检查。
4. 固定规格按真实容量阻止溢出，不裁切事实或无限缩字。长图超出 12000 高度同样阻止；完整长文不能保证每个固定规格都能承载。
5. 横版／Banner 采样实际文字区背景对比度；严格模式阻断不合格输出，试用模式保留警告并允许下载。长图采用固定纯色正文区，**未执行背景像素对比度采样**。
6. 当前实际校验包括字体／图像加载、内容容量、画布尺寸；尚未验证二维码可扫描性、画面语义或完整品牌视觉质量。
