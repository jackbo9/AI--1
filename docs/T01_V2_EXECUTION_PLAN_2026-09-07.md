## 需要补齐的设计契约

1. **主视觉尚未提供。** 此节点没有图片或明确图片槽。不能把中间空白直接当成已确定的全幅背景/裁切槽。先完成无图骨架Fixture；主视觉的范围、焦点、裁切与标题增长时如何避让须补充后再切换正式生成。可以提出“标题区以下、灰色信息区以上”的候选方案，但不得将其写成已确认规则。
2. **新文案槽来源。** “九号员工网球公开赛 / TENNIS”不能硬编码给所有活动。建议新增可选的活动名称眉题，主标题继续使用已锁定主题；英文分类须用户提供或来自已批准枚举，不自动杜撰。新增说明“晋升通道：详见报名页”仅在存在相应事实时展示。上场指南/先看这里/一起上场作为体育模板展示文案；非赛事活动需明确适配文案，不强制把所有category改成competition。
3. **二维码缺失。** 隐藏二维码及扫码报名文案，右列暂保留版式空间，不自动重排四格。一起上场和箭头是否仍保留需按含义确认；不能暗示存在未提供的报名入口。
4. **容量不是无限。** 14字通常需要两行，但真实分行由字体决定。建议输入安全上限沿用有限领域预算，超建议长度提示；发布前以实际文字边界和相邻槽碰撞阻断。主视觉未定前，不把旧版三行上限自动视作新版已批准容量。
5. **字体依赖。** 仓库有Regular/Medium/Semibold/Heavy，缺Bold。补齐获授权的MiSans Bold；禁止浏览器合成粗体替代。125px标题normal行高需用正确字体对照166px样例确认，再形成显式行高token。不能将单行高度固定为整个标题高度。
6. **信息事实完整。** 时间应保留日期与时段，不能照样例只显示日期。两场必须保持时间与地点关联；窄列超限应报错，不能删除第二场或省略地点。规则不能slice只显示前两条。

- [ ] **A：冻结正确基线与素材。** 复核分支、HEAD及dirty文件；读取AGENTS、README、HANDOFF、ARCHITECTURE、CONTRACTS。重新读取426:4及相关子节点，保存设计测量与导出资产；保留已有品牌文件，按尺寸参数复用。新增箭头使用Figma原资产。补字体，不新增模型或基础设施。
- [ ] **B：先做新版无图Fixture。** 新建独立版本的T01布局配置/markup，完成Logo、顶线、三层标题、灰底四格与二维码。先用一场赛事、14字标题、25字副标题生成PNG，核对间距、字体、网格；此时不切换生产默认，也不调用模型。
- [ ] **C：建立预览与导出共用的版式。** 优先复用同一套受控markup/CSS或共享无服务端依赖的模板组件，浏览器以1080×1920基准整体缩放。避免单独维护292px版的坐标、字号和max-height。草稿缺字段可显示占位，但确认后预览和导出必须使用同一内容投影；空副标题不得回退summary。生产布局与预览保持同字体、换行、22px间距。
- [ ] **D：同步表单、Schema、Prompt与确认。** 删除旧5字规则，增加14/25建议提示；建议超限不自动改写用户主题。新眉题及补充说明有明确字段来源/可编辑权限。Copy Prompt只针对允许编辑的字段生成结构化内容，主题与时间地点等逐字段锁定。服务端拒绝未知字段和超安全预算，不静默裁切。
- [ ] **E：实现真实容量预检。** 字体/资产加载后测量全部文本槽、四格、时间/地点、二维码及底部说明；同时检查水平越界、垂直越界和跨格碰撞。取消只查整组bottom的粗略判断。生图前预检与最终render共用同一函数。错误返回具体字段和修复建议；strict/trial都不能绕过容量错误。
- [ ] **F：补主视觉契约后接图片。** 更新模板独立的构图配置与Prompt版本，基于实际标题占用规定避让范围；不直接沿用旧“上方28%留白”和“中右主体”规则。灰色信息底板由代码绘制，不让模型画文字/Logo/二维码/表格。复核旧素材重新排版与新生图两条路径。信息区采用固定深字/浅底的实际像素检查，不套旧全幅背景的文字反白逻辑。
- [ ] **G：版本与其他规格回归。** 升级竖版templateVersion并追踪对应设计来源、内容/Prompt/资产版本；新输出追加，不覆写历史PNG。横版/Banner/长图不自动换成新设计。新眉题或主标题差异必须明确各规格字段投影，避免复制一个赛事样例到所有规格。
- [ ] **H：验收后再发布。** 新旧同输入对照；修复CI并确认通过；人工查看PNG与真实页面。确认无图骨架和主视觉均获验收后再切默认版本。发布记录实际commit、模板版本；push并不等于预览服务已运行该版本。

## 验收矩阵

- 标题13/14/15字符、副标题24/25/26字符，以及英文、数字、中文标点；超建议仍可编辑，不因建议长度被截断。
- 主标题1/2/3行仅作测量样例，按定稿安全区判定可用；缺眉题/副标题时自然收拢，无幽灵间距。
- 单场/双场、长地点、长时段、四条规则、空规则；无字段丢失、无网格覆盖。
- 有URL二维码、有上传二维码、无二维码；保持静区与原比例，验证实际扫描再声称可扫码。
- 桌面/窄屏同输入预览与PNG的行数、间距、模块位置一致；界面缩放不改变海报排版。
- 固定信息底色、字体缺失、图片失败、低对比、超容量路径；阻断错误不被trial放开。
- 当前分支运行typecheck、lint、单元/集成、构建、新版PNG与原活动多规格回归。CI提供Chromium及系统依赖后再运行浏览器排版测试，具体按失败日志修复。
